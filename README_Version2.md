# 🎮 Mafia Game Bot

A complete Telegram-based Mafia game bot with stats, store, and profile system.

## ✨ Features

✅ 15+ different roles
✅ Night & Day phases
✅ Player profile system
✅ In-game store with items
✅ Statistics tracking
✅ Currency system (Dollar & Diamond)
✅ Group chat support

## 📦 Items Available

- 🛡️ Protection
- 🔴 Killer Protection
- ⚖️ Vote Shield
- 🔫 Rifle
- 🎭 Mask
- 📄 Documents

## 🚀 Quick Start

1. Get bot token from @BotFather
2. Install: `pip install -r requirements.txt`
3. Add token to main.py or .env
4. Run: `python main.py`
5. Create group and use `/newgame`

## 🎮 Commands

- `/start` - Initialize bot
- `/profile` - View your profile & stats
- `/store` - Buy items & upgrades
- `/newgame` - Create new game
- `/startgame` - Begin game (4+ players)
- `/status` - Check game status
- `/help` - Show help

## 👥 Roles (15 Total)

**Civilians (10):** Detective, Sergeant, Mayor, Doctor, Hooker, Hobo, Citizen, Lucky, Suicide, Kamikaze

**Mafia (5):** Don, Mafia, Lawyer, Killer, Journalist

**Individual (6):** Maniac, Werewolf, Arsonist, Mage, Crook, Snitch

## 💰 Currency

- **Dollar** - Buy items in store
- **Brilliant (Diamond)** - Premium currency

## 📊 Stats Tracked

- Total games played
- Wins
- Winning score
- Items owned
- Currency balance
- Next role assignment

## 📁 Files

- `main.py` - Main bot code
- `config.py` - Configuration
- `.env` - Environment variables
- `requirements.txt` - Dependencies
- `player_stats.json` - Player data (auto-generated)
