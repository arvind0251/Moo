# 🎮 Mafia Game Bot

A complete Telegram-based Mafia game bot with all roles and game mechanics.

## 📋 Features

✅ Multiple Game Roles (15+ roles)
✅ Civilians vs Mafia vs Individual roles  
✅ Night & Day phases
✅ Automatic role assignment
✅ Player management
✅ Game status tracking
✅ Support for group chats
