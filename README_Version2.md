# 🎮 Mafia Game Bot

A complete Telegram-based Mafia game bot with all roles and game mechanics.

## Features

✅ 15+ different roles
✅ Night & Day phases
✅ Automatic role assignment
✅ Group chat support

## Quick Start

1. Get bot token from @BotFather
2. Install: `pip install -r requirements.txt`
3. Add token to main.py
4. Run: `python main.py`
5. Create group and use `/newgame`

## Commands

- /start - Start bot
- /newgame - New game
- /startgame - Begin game
- /status - Game status
- /help - Help

## Roles

**Civilians (10):** Detective, Sergeant, Mayor, Doctor, Hooker, Hobo, Citizen, Lucky, Suicide, Kamikaze

**Mafia (5):** Don, Mafia, Lawyer, Killer, Journalist

**Individual (6):** Maniac, Werewolf, Arsonist, Mage, Crook, Snitch
